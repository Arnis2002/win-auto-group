# Win Auto Group

A responsive dealership website for Win Auto Group, built with React, TypeScript, Vite, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm run lint
```

## Deployment

The site is configured for Vercel. Production builds use `npm run build`, with `dist` as the output directory. The Vercel rewrite configuration supports client-side routes.

## Data notes

Vehicle information is a snapshot and may become outdated. Confirm prices, availability, fees, and vehicle details with Win Auto Group. Demo forms on this site do not submit information to the dealership.
